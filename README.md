# CHYMP AI

### Cognitive Hybrid Multifunctional Partner

CHYMP AI is a web-based AI conversational assistant designed with a clean, modern interface and responsive chat experience.

## 🚀 Live Demo

https://hebronpeter376-art.github.io/ai-chatbot/

## ✨ Features

- AI-powered conversations
- Persistent conversation history
- New Chat functionality
- Clear Chat functionality
- Dark and light mode
- Responsive design
- Markdown-formatted AI responses
- Typing indicator
- Custom CHYMP AI branding
- Custom favicon
- Mobile-friendly interface

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- GitHub Pages
- Cloudflare Workers
- Make automation
- Marked.js
- DOMPurify

## 🎯 Project Goal

CHYMP AI was created as a practical AI assistant interface combining a modern frontend with an automated backend workflow.

## 📱 Interface

The interface is designed to provide a simple and comfortable conversational experience across desktop and mobile devices.
